# Fortune Cookie Wisdom for Developers

Entry for the make.fun bounty
[u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44):
write one original fortune-cookie line for a software developer,
120 characters or fewer.

## The entry

> Your legacy code was once someone's clever shortcut; be kind to its author — it was you, six months ago.

(104 characters.)

It reads like a fortune cookie — one short balanced sentence that lands
in a single breath — says something true about a developer's day
(legacy code), and turns that truth in a way the reader has not heard
before: the stranger whose code you curse is your own past self. The
quiet twist rewards a second read.

## How it works

`main.py` (Python standard library only) writes exactly that one line,
with no trailing newline, to `/output/entry.txt`. The program is
deterministic: every run produces byte-identical output.

Verified locally: the output file holds exactly 104 characters on one
line, valid UTF-8, and passes the kit's gate of 1–120 characters.
